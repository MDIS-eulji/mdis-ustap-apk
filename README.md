# U-StaP 시험용 설치 파일

MDIS의 U-StaP 일반 앱(욕창 단계별 관리 안내) 시험용 APK를 내려받는 곳입니다.
소스 코드는 이 저장소에 없습니다.

- **항상 최신 시험판 받기:** https://github.com/MDIS-eulji/mdis-ustap-apk/releases/latest/download/U-StaP-guide-test.apk
- 지난 시험판은 [Releases](../../releases)에 있습니다. 새 코드가 나올 때마다 새 릴리스로 올라갑니다.
- 모든 시험판은 같은 테스트 키로 서명되어 있어 이전 시험판 위에 덮어 설치할 수 있습니다.
- 시험용 테스트 키로 서명되어 있어 Google Play 버전과 다릅니다.
- 이 앱은 의료기기가 아니며 진단이나 치료를 대신하지 않습니다.

## 설치 방법

1. 휴대폰이나 PDA에서 위의 최신 주소를 열어 `.apk` 파일을 내려받습니다.
2. 파일을 눌러 설치합니다. "출처를 알 수 없는 앱" 경고가 나오면 허용합니다.
3. 앱 목록에 "U-StaP"로 나타납니다.
